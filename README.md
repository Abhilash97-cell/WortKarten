# WortKarten

An ad-free, offline German vocabulary trainer with approximately 5,000 German words and expressions, built for modern Android devices.

---

## ✨ Features

- **Offline-First:** Train your vocabulary anywhere without requiring an active internet connection or account sign-up.
- **5,000+ Words & Expressions:** Comprehensive German vocabulary spanning multiple levels (A1 to C1) and real-world categories (Daily Life, Work, Grammar, Tech, and more).
- **Spaced Repetition System (SRS):** Efficient learning algorithm optimized for long-term memory retention.
- **Modern UI / Material 3:** Clean, adaptive design with automatic light and dark mode support.
- **Custom Notes & Favorites:** Personalize your learning experience by adding notes and starring difficult words.
- **Data Backup & Export:** Easily export or import your learning progress via JSON and CSV backups.

---

## 🛠️ Tech Stack

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Toolkit:** [Jetpack Compose](https://developer.android.com/jetpack/compose) & [Material 3](https://m3.material.io/)
- **Architecture:** Modern declarative UI with reactive ViewModel state management
- **CI/CD:** [GitHub Actions](https://github.com/features/actions) for automated builds
