# WortKarten 🇩🇪

An ad-free, offline German vocabulary trainer for Android.

WortKarten contains approximately 5,000 German words and expressions with English translations, example sentences, article training (der / die / das), and spaced repetition learning.

## Download

Download the latest version from the Releases page:

➡️ https://github.com/Abhilash97-cell/WortKarten/releases/latest

## Installation

1. Open the latest release.
2. Download **WortKarten.apk**.
3. Open the downloaded APK on your Android phone.
4. Allow installation from unknown sources if Android asks.
5. Tap **Install**.

## Features

- Approximately 5,000 German words
- B1–C1 focused vocabulary
- English translations
- German example sentences
- Article training (der / die / das)
- Spaced repetition
- Daily reminders
- Progress tracking
- Topic-based learning
- Custom CSV import
- German pronunciation
- Offline learning
- No ads
- No account required
